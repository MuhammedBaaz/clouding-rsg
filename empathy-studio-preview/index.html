RSG concierge × Empathy Studio rich components — Phase 1 proposal board

Every card below is rendered by a line-for-line port of the Empathy Studio web-SDK renderers (carousel, carousel-card, selection-list-picker, grouped-list-picker, confirmation-card, buttons) with the SDK's own CSS, populated from the live RSG booking data and photographs. Theme hooks used are the SDK's supported ones only: --primary-color, --text-color, --border-color, --font-family, iconBaseUrl. Notes in the right-hand column are for the review, never for customers.

Data set: Switching re-renders every card with that version's data and theme.
